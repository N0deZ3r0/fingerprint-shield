Intl.DateTimeFormat.prototype.format — window scope

format is an ACCESSOR whose getter throws when read on the prototype, so the old var _fmt = OrigDTF.prototype.format; threw into catch(eFmt){} and the patch was never installed: formatToParts() substituted the spoofed timeZoneName while format() printed the host's. This page pins both the substitution and the exact native descriptor shape the replacement has to keep.
