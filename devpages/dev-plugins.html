navigator.plugins — the empty-PluginArray fallback, against the real thing

mw/mw-misc.js rebuilds navigator.plugins and navigator.mimeTypes, but only when the browser reports none. Real Chromium always ships the five PDF entries — headless included — so that branch never runs on its own and nothing in the suite ever executed it. It shipped for a long time assigning item, namedItem, refresh and Symbol.iterator as plain function expressions, which means String(navigator.plugins.item) printed this project's source.

This page forces the branch: it hides the real PluginArray behind an empty one before the content scripts load, lets them rebuild it, then compares the result against the native interface — names, argument counts, toString, own properties, iteration and brand. The reference values come from a clean same-origin iframe, so nothing here is a hard-coded idea of what Chrome does.
