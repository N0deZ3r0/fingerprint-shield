Worker patch — end to end

The injected worker patch is ~240 lines of JavaScript living inside a string in _buildPatchCode(). ESLint cannot see into it, and the whole thing is wrapped in try{}catch{} — so a syntax error there does not throw anywhere visible, it just silently leaves every worker unpatched. This page loads the real mw/mw-workers.js and lets its own Worker override build and inject the code, then asks the worker what it sees. If the generated script failed to parse, every row below goes red at once.
