Replaced APIs — object type, not just value

A recurring defect class in this codebase: a patch returns an object LITERAL where the browser returns a real interface instance, so instanceof fails, JSON.stringify shows own properties a native object never has, and the prototype is wrong. It was found and fixed for TextMetrics, PermissionStatus, BatteryManager and PluginArray. This page checks the ones still in the tree, so a new one cannot slip in quietly.
