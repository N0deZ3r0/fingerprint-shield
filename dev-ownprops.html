Own properties — patched window vs a pristine iframe realm

A patch that lands on an instance instead of its prototype leaves an own property the real object does not have, and enumerating own properties costs a detector one line. CreepJS does exactly this for navigator and screen ("failed undefined properties"), which is why _def() re-targets navigator/screen onto their prototypes and why the userAgentData getter was moved off the instance.

This page does not take a fixed list of names on trust: it diffs Object.getOwnPropertyNames for a set of objects — and their prototypes — against the same objects in a clean same-origin iframe, so anything the extension adds or removes shows up on its own.
