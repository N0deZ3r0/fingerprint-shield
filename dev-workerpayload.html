Worker payload — does the emitted script even compile?

_buildPatchCode() in mw/mw-workers.js assembles the script that is prepended to every worker. Whatever is still assembled from string literals is invisible to ESLint — no parse check, no no-undef — and the whole injection sits inside try{}catch{}, so a syntax error there does not throw anywhere visible: it silently leaves every worker unpatched, on every page, with a perfectly quiet console. That is the failure this page exists to make loud.

It captures the real Blob the Worker constructor is handed, compiles it with new Function (which parses without executing), and checks that the pieces the worker depends on are actually present.
